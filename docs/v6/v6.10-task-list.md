# v6.10.x 可执行任务清单

> **目标**：打造一个今天能用的 Autonomous Agent Workbench。
>
> **每阶段原则**：Agent 今天比昨天多会了一件什么事情？
>
> **核心规则**：UI 永远只认识 `PresentationModel`，不直接调用 Service。

---
